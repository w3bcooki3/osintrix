# Osintrix design POCs and audit

Standalone prototypes, separate from the app. Open any file in a browser (fonts load from Google Fonts; everything else is inline).

- `AUDIT-REPORT.html`: the product audit, with findings, design comparison and action plan.
- `a-casefile.html`: Concept A, reading-first case workspace (recommended backbone). Click marked indicators; press N to capture.
- `b-pinboard.html`: Concept B, graph-first board. Click nodes; drag or play the time bar.
- `c-console.html`: Concept C, keyboard-first console. Try `pivot 203.0.113.47`, `verdict:malicious`, `/` to focus, j/k to move.

All data is the synthetic Op Lantern demo case from js/demo.js.
